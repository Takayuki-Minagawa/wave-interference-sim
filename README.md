# wave-interference-sim

波の干渉と定常波を同じ UI 系で扱う高校物理向け Web シミュレーターです。2D 干渉モードでは複数波源の重ね合わせをカラーマップで可視化し、1D 定常波モードでは弦の境界条件ごとの節・腹・固有モードを観察できます。

## 機能

- 2D 干渉モード
- 2〜4 波源の配置変更
- 波長・周波数・振幅・位相の個別調整
- 強めあい線 / 弱めあい線 / 波面線の表示
- 観測点クリックによる時間変動グラフ

- 1D 定常波モード
- 両端固定 / 片側自由 / 両端自由
- 固有モード切替
- 張力・線密度・弦長・振幅・位相差の調整
- 節位置 / 腹位置 / 基本振動数比の表示

- 共通
- 日本語 / 英語切替
- ライト / ダークテーマ
- 学習パネルとクイズ
- GitHub Pages 配信向けの静的構成

## 開発

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

Lint:

```bash
npm run lint
```

## デプロイ

`.github/workflows/deploy.yml` で GitHub Pages へのデプロイを想定しています。`main` ブランチへの push でビルドし、`dist/` を Pages アーティファクトとして公開します。
